Desktop-First AI-Powered Web Application

Speak. Learn. Grow.


---

1. Project Overview

Bidya Guru ek AI-powered, multilingual Voice Career and Communication Mentor web application hai jo students ko unke career journey mein guide karega.

Student application mein securely email aur password se register/login karega. Login ke baad student AI ke saath voice-to-voice conversation kar sakta hai.

Student Odia, Hindi, ya English mein baat kar sakta hai. AI student ki language, career goal aur current skills ko samjhega.

AI student ko:

- Career field identify karne mein help karega
- Current skills samjhega
- Personalized career roadmap generate karega
- Voice ke through career guidance dega
- Communication skills practice karwayega
- Progress track karega

Gnani API project ke voice/speech communication ke liye use hoga, aur Gemini API AI intelligence, career guidance, roadmap generation aur communication feedback ke liye use hoga.


---

2. Problem Statement

Bahut students ko problems hoti hain:

- Kis career field mein jana hai
- Target career ke liye kya skills chahiye
- Current skills kaise identify karein
- Learning kis order mein karein
- Career roadmap kaise banayein
- Communication skills kaise improve karein

Existing platforms mein guidance often generic hoti hai aur typing-based interaction hota hai.

Bidya Guru ek conversational AI mentor provide karega jahan student natural voice conversation ke through personalized guidance le sakta hai.

22. Security Requirements

Bidya Guru ko secure banane ke liye:

Password Security

- Passwords plain text mein store nahi honge
- Argon2 password hashing use hoga

Authentication

- JWT-based authentication
- Short-lived Access Token
- Refresh Token strategy
- Token rotation where applicable

Secure Token Storage

- HttpOnly Cookies
- Secure Cookies in production
- Appropriate SameSite configuration

API Security

- Rate limiting
- Helmet security headers
- CORS allowlist
- Input validation using Zod/Joi
- Request size limits
- Centralized error handling

Authorization

Backend har protected request mein verify karega:

> Kya user authenticated hai?



Aur:

> Kya requested resource usi user ka hai?




---

23. Database Security

MongoDB Atlas ke liye:

30. Success Criteria

The project will be considered successful when:

1. A student can securely create and access an account.
2. The student can communicate with Bidya Guru through voice.
3. The system can understand the student's career goal.
4. The system can understand and organize current skills.
5. Gemini generates a personalized career roadmap.
6. The student can track roadmap progress.
7. The student can practice communication using voice.
8. AI provides useful communication feedback.
9. Gnani is clearly demonstrated as the project's core voice technology.
10. Gemini is clearly demonstrated as the project's AI intelligence and career guidance technology.
11. The application has a clean, professional, desktop-first UI.


---

31. Final Project Statement

> Bidya Guru is a multilingual AI-powered Voice Career and Communication Mentor that helps students talk naturally in their preferred language, identify their career direction, understand their current skills, receive a personalized career roadmap, practice communication, and track their progress through a clean and secure desktop web application.
